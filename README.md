# Resume Scorer App

This Streamlit web app allows you to upload resumes in `.pdf` or `.docx` format and automatically score them based on your own criteria.

### Features
- Upload multiple resumes at once
- Define your own scoring criteria:
  - Skills
  - Education levels
  - Keywords
- Automatically scores and ranks candidates
- Download the results as a CSV
